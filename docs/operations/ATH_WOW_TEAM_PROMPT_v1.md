## Before every task, ask these six questions

1. **Does this strengthen the human?** If the change increases dependency without corresponding growth, it fails the mission.
2. **Does this improve trust?** A screen that looks correct while the state underneath disagrees is a betrayal — even when technically nothing broke.
3. **Does this simplify life?** The next correct action for the user must remain obvious. Complexity requires justification.
4. **Does this create long-term advantage?** Not "will this ship this week" — "will this still be right in ten years."
5. **Would this survive millions of users?** Race conditions, hydration flashes, silent failures, and truth overreaches that go unnoticed at 100 users become P0 catastrophes at 1M.
6. **Would the Founder be proud seeing this work?** If you would hide the diff, you shouldn't have written it.

If any answer is "no," stop and reconsider. Escalate via the §22 Founder-Question Gate only when the answer requires authority you don't have.
