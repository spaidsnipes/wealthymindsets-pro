| Status | Meaning |

| **PARTIALLY PROVED** | Built, and some of it is read on serving or on a fixture. What is missing is named. |
| **OPEN** | Not built, built but never read on serving, or in flight in another lane's uncommitted tree. |

**Row-level vs domain-level status.**

- Sections 1–5 are **row-verified**. Each row cites code, a test and a serving read, or says which of these is missing.
- Section 6 (the ~770 Drive canon rows) carries a **domain pointer** unless the row is marked ROW-VERIFIED. The pointer is the status of the release line or certificate that governs that domain.
- A domain pointer keeps the requirement from being lost. It is not proof that the row is met. Verifying each pointed row against code and glass is the open work of this register; see §8.
